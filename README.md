Students Marks Analysis

This is a simple Python project to analyze student marks from a CSV file.

Project Structure:

students-marks-analysis/
- data/students_marks.csv
- src/analysis.py
- charts/ (output charts)(terminal_output.png)
- requirements.txt
- README.md

How to Run:

pip install -r requirements.txt

python src/analysis.py

What it does:

- Calculates total, average and grade for each student.
- Finds the topper and class average.
- Creates charts for average marks and subject wise performance.

Proof of Work:

terminal_output.png` 


Charts are saved in charts folder after running the script.

Tech used: Python, Pandas, Matplotlib
